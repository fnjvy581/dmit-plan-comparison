## 三档线路的差别，决定你该花多少钱

Premium 走三网 CN2 GIA：电信 CN2 GIA、联通 AS9929、移动 CMI/CMIN2，国内访问延迟和丢包控制最好，价格也最高。Eyeball 走 CMIN2 和 AS9929，属于有优化但不堆满配的中间档。Tier 1 是普通国际 BGP，没有任何中国大陆专属优化，胜在便宜、流量给得多。

这里有个常见的误买：看到 Eyeball 比 Tier 1 贵一点，就以为“贵的一定带 CN2 GIA”。Eyeball 不是 CN2 GIA 线路，它优化的是移动和联通方向。真要三网 CN2 GIA，只有 Pro。

反过来的误判也存在。不少人觉得 T1 是“残废线路”，其实建站、跑 API、做中转、面向海外用户的产品，T1 完全够用，国内访问慢一点但不影响业务本身。判断标准很简单：你的用户在哪。用户在国内且在意打开速度，Pro 或 EB；用户在国外，或者你只是要一台机器干活，T1。

## 常见问题

**T1 线路到底够不够用？**
看你用户在哪。建站、跑脚本、部署工具、面向海外用户的产品，T1 够。需要国内访问快，T1 不行，换 EB 或 Pro。国内访问洛杉矶 T1 不是不能用，只是晚高峰体验和优化线路差一截。

**Pro 比 EB 贵在哪？**
贵在三网 CN2 GIA。EB 优化的是移动和联通方向，走 CMIN2/AS9929；Pro 是电信、联通、移动三网都走精品线路。国内用户构成复杂、电信用户占比高，Pro 的稳定性优势才明显。

**AN4 和 AN5 怎么选？**
吃 CPU 的选 AN5，多核跑分约 11829，比 AN4 提升明显，代价是同档贵 30% 以上。只做代理、静态站、轻量服务，AN4 的 EPYC 9004 足够。

**优惠码填了提示无效怎么办？**
先确认计费周期，月付基本用不了；再确认套餐系列和档位是否在适用范围内；最后确认码有没有过期。三个都对还是无效，就按原价买，或者换一个码试。

**IP 被墙了怎么处理？**
Pro 和 EB 满足条件每 15 天可免费换一次，控制面板自助操作；T1 只能 $5 付费换。换 IP 是随机分配，不能指定地区或网段，换完不可撤销。

**支持什么付款方式？**
支付宝、微信、PayPal、信用卡。
